MobilMotorLama – Managing Indonesian Automotive Website

Mobilmotorlama initially was created as a hobby project in 2015. The topic is discussing vintage cars and motorcycles that once existed in Indonesia. As a hobby project, I served as the end to end publisher and technical lead (web admin, content strategist, photographer, and frontend tweaker).

This site was built using the Blogger/Blogspot platform, and then assigned a custom domain (.com). This was chosen because the Blogger platform is easier to modify with XML template customizations and is free, so I don’t have to worry about bandwidth, hosting, or other things. This reduced my workload and allowed me to focus solely on writing. To enhance my site professionalism, I assigned a .com domain and then a CNAME record pointed to Blogspot.

Challenges

Running a content heavy platform using a PaaS/No-code platform like Blogger has its own limitations, such as:

  • Poor site performance and loading speed due to heavy reliance on external resources
  • Blogger’s default XML/HTML structure is less flexible for modern User Experience (UX) needs
  • Optimization by ensuring code structure and content adhere to Google Search Console standards

Solution

Front End Solution

Even though I use Blogger’s infrastructure, I manually make changes to the code to improve the website’s functionality and aesthetics. I modify Blogger’s custom XML structure to add related posts, breadcrumb navigation, and more. This makes the website more responsive for mobile users and prevents high bounce rates with a well-designed navigation menu.

Performance Optimalization

To maintain reader comfort, site loading speed must be kept to a minimum. One step is to reduce image sizes, such as limiting image dimensions to 800×450 pixels and using a smaller webp extension. Currently, the site still uses images with a JPG extension with a resolution of 800×450 pixels because converting thousands of existing photos is quite time-consuming. Furthermore, the use of external JavaScript is minimized to a certain extent because Google AdSense, a revenue source, requires JavaScript, which significantly impacts site performance.

Technical

To showcase this site to the world, SEO (search engine optimization) techniques are required. I manage robots.txt to indicate to search engines what to index and what not to index, sitemaps, and other features to integrate with services like Google Search Console. Furthermore, I pay attention to writing format by implementing a heading hierarchy (H1, H2, H3), optimizing image alt text, and using a structured internal linking strategy between related articles.

Current Condition

After more than 10 years, Mobilmotorlama has faced several challenges, such as a shift in Indonesian interest toward audio visual content due to increasingly affordable internet costs. Not to mention the proliferation of AI chatbots, which are making people increasingly reluctant to visit websites to search for information.

As a result, Mobilmotorlama currently only receives around 2,000-3,000 daily visitors. However, this figure, based on raw pageviews on the Blogger dashboard, can differ significantly because raw pageviews also include bots, crawlers, and navigation between pages by the same user. Therefore, statistics from services like Google Search Console, which calculates total organic clicks purely from search engines (real user intent), better reflect the true situation. In Google Search Console, the average daily visitor count is only 300 to 500 visitors.

This is because the site is rarely updated due to busy schedules, which also reduces interaction with readers. This also impacts search rankings. Although many articles remain on the front page, their rankings have dropped to positions 6 and above, resulting in a relatively high click-to-view ratio. This also impacts updates to anticipate various Google search engine algorithm updates.

To address this, I’ve started converting some articles into video format and uploading them to YouTube. I’m also gradually updating older articles over 5 years old, as Google’s current algorithm favors newer or updated articles with additional internal links, improved wording, updated information, and more
